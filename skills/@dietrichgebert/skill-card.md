## Description:

Guides coding agents to make the smallest complete change and explain it concisely.

This skill is ready for commercial/non-commercial use.

## Publisher:

[dietrichgebert](https://clawhub.ai/user/dietrichgebert)

### License/Terms of Use:

MIT-0

## Use Case:

Developers use this skill to guide a coding agent toward minimal, complete changes that follow project conventions and are easy to review.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Session-wide minimalist guidance may limit broader design exploration or detailed review.

Mitigation: Use 'stop ponytail' or 'normal mode' when ordinary behavior is needed.
